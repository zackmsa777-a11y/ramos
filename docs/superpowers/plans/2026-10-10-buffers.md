# Ramos 0.5 implementation plan

Spec: `docs/superpowers/specs/2026-10-10-buffers-design.md`.
Execute inline; independent whole-branch reviewer after tests pass.
Base: `08e2a9f`. Preserve the prior 0.4 branch.

## Task 1: integration contracts

- Extend `tests/test_ramos.py` with actual compiled/executed buffer programs.
- Remove obsolete rejection of string-valued local declarations.
- Verify new tests fail on absent buffer functionality, retaining 60 green old tests.
- Cases: empty/zero-filled/max-size buffers, ASCII/UTF-8/NUL, aliases and independent
  literals, escaping frames, recursive/nested buffer calls, left-to-right writes,
  bad types/arity/shadowing, negative/extreme size/index/value and arena exhaustion.

## Task 2: typed IR and parser

- `src/ramos.s`: bytes keyword/type and bounded IR opcodes; NUL escape.
- New `src/buffers.inc`: fixed intrinsic signature table, bounded lookup and
  argument checking. Integrate `src/functions.inc` call/name/type checking.
- `src/parsing.inc`: literal expressions, buffer printing and forbidden comparison.
- Interface: one opaque 64-bit buffer handle in existing local slots/stack ABI;
  IR_BUILTIN carries intrinsic index; IR_BUFFER_LITERAL carries data offset/length.

## Task 3: native buffer operations

- New `src/buffer_runtime.inc`, copied inside existing position-independent runtime:
  lazy RW mmap, checked aligned monotonic allocation, literal copy, get/set/len,
  buffer print and explicit errors. Reserve r13/r14 runtime state.
- New `src/buffer_codegen.inc`: intrinsic argument pops into rax/rcx/rdx,
  runtime rel32 calls, literal addresses using existing data fixups.
- `src/codegen.inc`: dispatch new IR and share literal-address fixup helper.
- Verify new and old suites pass and output retains RX/R/non-executable stack.

## Task 4: delivery

- Add `examples/buffers.ramos`, make target, `docs/buffers.md`, README and roadmap.
- Bump version to 0.5, run clean full suite and examples, independent review.
- Install, commit, attempt GitHub branch/PR; if blocked preserve source, binary,
  patch series, branch bundle and test evidence in a saved archive.

## Review focus

Evaluate arena metadata/padding at exact bounds, errors before memory access,
register preservation through runtime/syscalls/recursion, separate literal
evaluations, nested intrinsic argument effects and compiler limit behavior.
Check direct literal printing versus buffer expression printing consistency.
